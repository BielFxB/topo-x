# Topo X - Landing page

Site de uma página, em HTML, CSS e JavaScript puros. Não precisa instalar nada: abra `index.html` no navegador.

## Trocar o número do WhatsApp

Edite a primeira linha de `js/main.js`:

```js
const WHATSAPP_NUMERO = "5518999999999"; // 55 + DDD + número
```

Todos os botões do site usam esse número.

## Estrutura

```text
index.html
css/style.css
js/main.js
assets/img/   logo e fotos
```

## Publicar

Envie a pasta para Netlify, Vercel, GitHub Pages ou para a hospedagem do seu domínio.
